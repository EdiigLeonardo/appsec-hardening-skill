# External interactions

Review all outbound and inbound integrations.

Outbound:

destination control; protocol control; redirects; private/internal destinations; response size; timeouts; trust of remote content.

Inbound:

authenticity; integrity; replay resistance; ordering; idempotency; schema validation.


## Error handling and failure modes

Review:

fail-open behavior; exception handling; fallback behavior; partial failures; retry behavior; timeouts; dependency failures.

Security rule:

Authorization, validation, and integrity controls should fail closed where appropriate.
