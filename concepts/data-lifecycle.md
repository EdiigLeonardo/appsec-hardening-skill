# Output and data exposure

Review:

excessive fields; hidden/internal metadata; secrets; tokens; security decisions; personal data; cache behavior; error messages; logs.

Rule:

Return only the minimum information needed by the recipient.

## Data lifecycle and privacy

Review:

collection; purpose; minimization; classification; retention; deletion; export; archival; backups; analytics copies; test/dev copies.

Ask whether the system stores more precision, history, or personal data than required.
